# 轮回仙途

一个以文字选择、自动战斗、随机事件、残魂复活和多周目轮回为核心的网页修仙肉鸽原型。

所属组织：[Always-on-holiday](https://github.com/Always-on-holiday)

## 当前原型

- 最多四名玩家通过同一房间码进入同一个世界
- 房主可以开启或关闭 PVP
- 世界由房主电脑持续运行，临时公网网址用于邀请朋友
- 房间、周目和联机生死状态保存在房主电脑；角色详细存档保存在每名玩家自己的浏览器
- 单个玩家死亡后化为残魂，仍可托梦、探查、附物、扰乱、吸灵或自行聚魂
- 存活玩家可用灵石、灵力或养魂木复活同伴，复活者保留死亡前境界
- 全员死亡后世界回到起点，每人可各继承一部功法、一件物品和一段记忆
- 二周目继承搜魂术后，可以从新手守门人处开启特殊轮回剧情
- 普通终局目标为永生，之后可以进入无限模式

目前仍处于联机与核心循环验证阶段，剧情、境界、数值和完整战斗系统会继续扩展。

## Windows 本地运行

请通过仓库的 **Code → Download ZIP** 或 GitHub Desktop 获取项目。Releases 页面中的 `v0.1.0`、`v0.1.1` Windows EXE 已被代码回退，目前不要使用；新的单文件版本尚未发布。

下载项目后直接双击 `一键启动互联网联机.bat`，无需预先安装 Node.js 或 pnpm。首次运行会自动下载并校验游戏专用的 Node.js `22.23.2`、安装依赖并构建网页，可能需要几分钟。

启动器会打开游戏网页，并在黑色窗口中显示可发给朋友的临时邀请网址。首次运行需要连接 Node.js 与 npm 的官方下载服务。

黑色窗口必须保持开启。关闭窗口后，临时网址会失效；下次启动会生成新网址，但本地世界存档不会丢失。

## 快速修改文字

双击 `打开内容配置.bat`，使用记事本修改 `public/游戏内容/界面文字.json` 中双引号里的文字。保存后关闭黑色窗口并重新启动游戏即可，无需重新构建。

`storyParagraphs` 是剧情段落列表，可以继续增加新行。详细格式见同一文件夹内的 `修改说明.txt`。

## 世界存档

存档默认位于项目文件夹上一级的 `世界存档/默认世界`。请勿把该文件夹提交到 GitHub。

备份或转移存档时：

1. 先关闭游戏服务器的黑色窗口。
2. 复制整个 `默认世界` 文件夹。
3. 不要在游戏运行时复制或手动修改其中的数据库文件。

世界种子只负责重现初始生成结果。房间周目和联机生死状态由世界数据库持续记录；人物经历、物品、功法和前世履历保存在玩家当前浏览器中。

## 主要目录

- `app/`：网页和服务器功能
- `components/game/`：按界面职责拆分的游戏面板
- `hooks/`：联机、本地存档、内容读取和自由行动流程
- `lib/client/`：浏览器端共用类型与轻量工具
- `db/`：数据库访问与结构
- `drizzle/`：数据库迁移
- `scripts/launcher/`：拆分后的 Windows 启动器模块
- `scripts/tests/`：启动器与运行环境回归测试
- `public/`：静态资源
- `public/游戏内容/`：无需修改网页代码的文字配置
- `public/游戏内容/轮回规则.json`：残魂、复活、继承和二周目特殊剧情

开发时的文件职责和修改边界见 [代码结构说明](docs/ARCHITECTURE.md)。
