# 轮回仙途

一个以文字选择、自动战斗、随机事件和死亡转生为核心的网页修仙肉鸽原型。

## 当前原型

- 最多四名玩家通过同一房间码进入同一个世界
- 房主可以开启或关闭 PVP
- 世界由房主电脑持续运行，临时公网网址用于邀请朋友
- 人物、房间和世界进度保存在房主电脑的本地数据库中
- 死亡后转生，后续计划允许继承一件物品、一段记忆和一部功法
- 普通终局目标为永生，之后可以进入无限模式

目前仍处于联机与核心循环验证阶段，剧情、境界、数值和完整战斗系统会继续扩展。

## Windows 本地运行

需要 Node.js `22.13.0` 或更高版本。

首次下载项目后，在项目目录安装依赖并构建：

```powershell
corepack enable
pnpm install --frozen-lockfile
pnpm run build
```

之后双击 `一键启动互联网联机.bat`。启动器会打开游戏网页，并在黑色窗口中显示可发给朋友的临时邀请网址。

黑色窗口必须保持开启。关闭窗口后，临时网址会失效；下次启动会生成新网址，但本地世界存档不会丢失。

## 世界存档

存档默认位于项目文件夹上一级的 `世界存档/默认世界`。请勿把该文件夹提交到 GitHub。

备份或转移存档时：

1. 先关闭游戏服务器的黑色窗口。
2. 复制整个 `默认世界` 文件夹。
3. 不要在游戏运行时复制或手动修改其中的数据库文件。

世界种子只负责重现初始生成结果；人物经历、物品、死亡、转生和世界变化由数据库持续记录。

## 主要目录

- `app/`：网页和服务器功能
- `db/`：数据库访问与结构
- `drizzle/`：数据库迁移
- `scripts/`：本地运行和联机启动脚本
- `public/`：静态资源
