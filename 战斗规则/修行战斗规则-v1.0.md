# 修行战斗规则 v1.0

## 1. 设计目标

这是一套以 d100 为核心的修行题材人物与战斗规则。人物能力来自属性、等级、境界、技能、功法、灵根、背景、天赋与装备；一次行动还会受到伤势、环境、克制关系和随机波动影响。

系统使用两层结果：检定过程中保留八个内部表现档位，以细分同为成功或失败时的质量；进入伤害、战果和剧情结算时统一折叠为“大成功、成功、失败、大失败”四档。

战斗结果不仅包括胜负，还可能是完胜、惨胜、逃脱、被俘、重伤、修为受损、装备损坏、两败俱伤或死亡。

所有精确算式、取整规则、判定顺序和代码伪逻辑均收录在配套文件《修行战斗规则-公式规范-v1.0.json》中。本文件以玩法说明和范例为主。

## 2. 核心术语

- 永久技能值：记录在人物卡上的技能值，可以超过100。
- 难度技能值：永久技能值经过难度倍率调整后的数值。
- 最终目标值：加入辅助技能、装备和临时状态后的检定目标。
- 内部档位：天成、卓越、优势成功、普通成功、惜败、明显失败、严重失误、灾难性失误。
- 最终四档：大成功、成功、失败、大失败。
- 克制值：在护甲与常规减伤之后结算的固定加减值。
- 功法乘区：功法单独提供的伤害倍率，同一次攻击通常只采用一个主要功法乘区。

## 3. 人物等级与境界

人物等级为1—100，每十级对应一个大境界。

| 等级 | 境界 |
|---|---|
| 1—10 | 锻体 |
| 11—20 | 练气 |
| 21—30 | 筑基 |
| 31—40 | 结丹 |
| 41—50 | 元婴 |
| 51—60 | 化神 |
| 61—70 | 炼虚 |
| 71—80 | 合体 |
| 81—90 | 大乘 |
| 91—100 | 渡劫 |

每个境界内部再分为：第1—3级为初期，第4—6级为中期，第7—9级为后期，第10级为圆满。例如27级为筑基后期，30级为筑基圆满。

升级提供生命、灵力、技能训练与阶段性属性成长。跨越大境界需要突破检定。突破失败不会清空等级经验，但可能造成材料损失、修为不稳、经脉伤势或心魔。

建议成长节奏：每升一级获得5点技能训练；每5级获得1点属性成长；每10级获得一个新天赋或强化已有天赋。主持人可根据战役长度调整。

## 4. 基础属性

普通人的属性一般为3—18，10代表普通成年人的平均水平。高阶修士、特殊血脉、妖兽和法宝化形者可以超过18。

| 属性 | 主要用途 |
|---|---|
| 力量 | 近战威力、负重、擒抱、破坏 |
| 体魄 | 生命、耐力、抗毒、伤势承受 |
| 敏捷 | 身法、闪避、先攻、精细动作 |
| 智识 | 学识、战术、炼丹、阵法 |
| 意志 | 专注、精神抵抗、恐惧与心魔 |
| 灵觉 | 术法、御器、神识、感知灵气 |
| 魅力 | 交涉、威慑、领导、欺骗 |

推荐创建方式：七项属性初始为8，再分配28点；创建时单项通常不高于16。背景、血脉与天赋可令属性达到17或18。

衍生数值包括最大生命、最大灵力、先攻和负重。其精确公式见公式规范。

## 5. 灵根、背景与天赋

### 5.1 灵根

灵根决定对应功法经验的获取效率，也决定人物能否顺利修炼特定属性功法。

| 灵根品质 | 对应功法经验倍率 |
|---|---:|
| 杂灵根 | 0.80 |
| 四灵根 | 0.90 |
| 三灵根 | 1.00 |
| 双灵根 | 1.15 |
| 单灵根 | 1.30 |
| 天灵根或特殊道体 | 1.50 |

灵根不直接决定胜负。灵根普通但战术、技能和装备优秀的修士，仍可能击败天资更好但缺乏经验的对手。

### 5.2 背景

每个背景建议提供两项技能加值、一项资源和一项关系或限制。

| 背景 | 技能与资源示例 |
|---|---|
| 宗门外门 | 刀剑+8、修行知识+8；制式武器与宗门身份 |
| 山野猎户 | 弓术+10、生存+8；猎弓与野外据点 |
| 丹师学徒 | 炼丹+10、药理+8；基础丹炉 |
| 世家旁支 | 交涉+8、礼法+8；家族联系人 |
| 流亡散修 | 身法+8、洞察+8；隐秘逃生路线 |

### 5.3 天赋

普通人物创建时选择两个天赋。天赋可以提供约+5的稳定加值，或每场战斗一次的特殊能力。

- 剑心通明：御剑检定+5。
- 烈焰直觉：每场战斗可重投一次火行检定。
- 铜皮铁骨：受到的物理伤害减少2点。
- 灵台清明：抵抗幻术、恐惧和心魔时+10。
- 越战越勇：生命低于一半时，近战技能+5。
- 丹心妙手：炼丹大失败可降为普通失败，每次炼制限一次。
- 危机感应：通常不会因伏击而失去第一回合。

## 6. 技能

技能由两项相关属性、训练、背景、天赋和永久成长构成。技能不设100上限。

| 技能值 | 能力层次 |
|---:|---|
| 1—30 | 未经训练 |
| 31—50 | 熟练 |
| 51—70 | 专业 |
| 71—90 | 精锐 |
| 91—100 | 大师 |
| 101—150 | 超凡 |
| 151—200 | 宗师 |
| 201—300 | 一代绝巅 |
| 301以上 | 神话层次 |

常见技能及相关属性如下。

| 技能 | 相关属性 |
|---|---|
| 刀剑 | 力量+敏捷；御剑流派可用敏捷+灵觉 |
| 拳脚 | 力量+敏捷 |
| 身法 | 敏捷+智识 |
| 弓术 | 敏捷+灵觉 |
| 火行术法 | 智识+灵觉 |
| 炼丹 | 智识+灵觉 |
| 阵法 | 智识+意志 |
| 坚韧 | 体魄+意志 |
| 洞察 | 智识+意志 |
| 神识 | 灵觉+意志 |
| 交涉 | 魅力+智识 |
| 威慑 | 魅力+意志，或力量+意志 |

炼丹、炼器、高阶阵法等专业技能在训练值为0时只能进行常识性尝试，不能制造正式成果。

### 6.1 超过100的意义

技能超过100不会被截断。它会扩大大成功范围、提高成功质量、降低大失败率，并使人物在困难环境或对抗中维持优势。

真正的永久技能超过100时，99可以正常参与判定，只有100必然触发灾难性失误。技能不超过100时，99和100都可能触发大失败。依靠极易环境、辅助技能或临时装备把目标值推过100，不等同于永久技能真正突破100。

## 7. 难度与辅助技能

难度以倍率调整技能，而不是堆叠大量零散修正。

| 难度 | 倍率 | 典型情况 |
|---|---:|---|
| 极易 | 2.00 | 工具齐全、时间充足、目标配合 |
| 容易 | 1.50 | 条件有利、充分准备 |
| 标准 | 1.00 | 正常情况 |
| 困难 | 0.67 | 轻伤、视野差、时间紧迫 |
| 艰难 | 0.50 | 重伤、复杂操作、强烈干扰 |
| 奇迹 | 0.10 | 几乎超出当前能力层次 |
| 不可能 | 不可检定 | 缺乏必要手段或前置条件 |

同类影响先互相抵消，再确定最终难度。轻微因素仍可提供+5或−5，显著的装备或状态通常提供+10或−10。

一个相关技能可以辅助主技能，通常提供该辅助技能五分之一的加值。每次检定原则上只能使用一个辅助技能。辅助可以扩大普通成功范围，但不会扩大大成功范围。

## 8. d100检定与八个内部档位

投掷1d100。骰值越低，表现越好。

系统按顺序判断八个内部档位：

| 内部档位 | 含义 | 最终四档 |
|---|---|---|
| 天成 | 接近人物能力极限的完美发挥 | 大成功 |
| 卓越 | 决定性的优秀发挥 | 大成功 |
| 优势成功 | 明显高于基本要求 | 成功 |
| 普通成功 | 完成预定目标 | 成功 |
| 惜败 | 接近成功，可以考虑付出代价 | 失败 |
| 明显失败 | 未能实现目标 | 失败 |
| 严重失误 | 产生一个严重后果 | 大失败 |
| 灾难性失误 | 产生两个严重后果或一个致命后果 | 大失败 |

八档只负责表现质量、同档对抗和特殊效果。进入伤害计算时，“天成”和“卓越”都按大成功结算，“优势成功”和“普通成功”都按成功结算。

建议允许惜败者选择“付出代价后成功”，例如消耗额外灵力、暴露位置、损坏工具、耗费更多时间或让敌人获得优势。重要剧情节点是否允许由主持人决定。

## 9. 对抗检定

攻击与闪避、擒抱与挣脱、追逐与逃脱、潜行与侦察均使用对抗检定。

比较顺序为：

1. 比较最终四档。
2. 四档相同时比较内部档位。
3. 内部档位相同时比较成功差值。
4. 仍相同时，永久技能值较高者获胜。
5. 再相同则形成僵局。

当至少一方的有效技能超过100时，采用超百归一：将最高者超出100的部分从所有参与者的有效技能中同时扣除。这样最高者按100检定，而技能差距完整保留。

例如160对110，双方同时减60，最终按100对50检定；160对70则变成100对10。归一后降至0或以下的一方无法靠普通检定获胜，必须先利用克制、阵法、法宝、偷袭或环境改变条件。

## 10. 功法

功法等级为0—100。功法可以提供属性、抗性、特殊招式、灵力效率和独立伤害乘区。

当人物确实使用对应功法并支付灵力时，才应用功法乘区。同一次攻击通常只能采用一个主要功法乘区；辅助功法提供固定加值、难度调整或标签效果，避免无限叠乘。

功法等级越高，独立乘区越强：20级约为1.10，50级约为1.25，80级约为1.40，100级为1.50。

功法经验受灵根、师承、修炼环境和资源影响。跨属性修炼可以进行，但可能降低经验效率或提高走火入魔风险。

## 11. 战斗流程

每轮战斗按以下顺序处理：

1. 根据先攻确定行动顺序。
2. 行动者选择攻击、施法、防御、移动、使用物品、擒拿、交涉或逃脱。
3. 攻击者与防御者进行对抗检定。
4. 根据最终四档和内部档位判断是否命中及命中质量。
5. 结算伤害、伤势、状态、灵力与装备耐久。
6. 检查昏迷、投降、逃脱、被俘和死亡条件。

攻击普通获胜时为普通命中；攻击者胜出两个或更多最终等级，或大成功击败对方的失败时，通常构成重击。防御者胜出两个或更多等级，可以获得反击、缴械、拉开距离或保护同伴的机会。

### 11.1 四档战斗结算

| 最终结果 | 默认处理 |
|---|---|
| 大成功 | 重击；伤害提高，并获得特殊效果 |
| 成功 | 正常命中或实现行动目标 |
| 失败 | 未命中或未实现目标 |
| 大失败 | 出现破绽、失衡、反击或装备损坏 |

天成大成功可选择两个特殊效果，卓越大成功选择一个。特殊效果包括击退、缴械、穿甲、压制、改变位置、打断施法、制造伤口或保护同伴。

## 12. 伤害构成

伤害依次纳入以下部分：

- 武器、法术或妖兽攻击的基础威力；
- 相关属性提供的威力；
- 装备强化与符文加值；
- 招式固定加值；
- 成功或大成功倍率；
- 功法独立乘区；
- 境界压制乘区；
- 环境乘区；
- 随机波动；
- 护甲与格挡；
- 最终克制加值与抗性。

随机波动使用1d20：1—4为0.90，5—8为0.95，9—12为1.00，13—16为1.05，17—20为1.10。

### 12.1 境界压制

| 境界差 | 乘区 |
|---|---:|
| 同境界 | 1.00 |
| 高一个大境界 | 1.15 |
| 高两个大境界 | 1.30 |
| 低一个大境界 | 0.85 |
| 低两个大境界 | 0.70 |

继续按每个大境界约15%的幅度延伸，最终限制在0.50—1.75。法宝、阵法、燃烧寿元和专门功法可以暂时抵消境界压制。

### 12.2 克制关系

克制值在护甲和常规减伤之后结算。例如火弱点5使目标承受火焰伤害时最终伤害增加5；雷抗性3使雷电伤害减少3。

克制仅在攻击带有对应标签时生效。是否在基础伤害被完全抵消后仍触发弱点，取决于弱点标签；“遇火自燃”可以触发，“火焰易伤”则通常要求攻击先造成至少1点伤害。

## 13. 伤势、修为与装备

### 13.1 伤势

- 单次承受最大生命10%以上的伤害，可能产生轻伤；相关行动通常−5。
- 单次承受最大生命35%以上的伤害，或当前生命降至30%以下，产生重伤；相关行动通常−15。
- 生命降至0或以下，失去正常行动能力并进入濒死。
- 生命降至负最大生命的一半，通常直接死亡。

濒死者每轮进行坚韧检定。成功可稳定伤势，大成功可能恢复意识；失败累计一次濒死失败，大失败累计两次。累计三次濒死失败即死亡。

恢复生命不自动移除伤势减值。轻伤、重伤和经脉损伤需要对应的治疗、丹药或休养。

### 13.2 修为受损

普通生命损失不会自动降低修为。只有经脉、丹田、元婴或神魂受到针对性攻击，濒死检定大失败，强行突破失败，使用燃烧修为的禁术，或被吸取根基时，才进行修为损伤结算。

轻度修为受损可暂时降低功法5—10级；严重损伤可能损失人物等级或境界，但应保留疗伤、重修或奇遇恢复的途径。

### 13.3 装备损坏

装备通常具有1—20点耐久。格挡重击、格挡大失败、承受破甲攻击或接触腐蚀与极端环境时损失耐久。耐久降至一半时装备加值降低1点；降至0时装备失效或破碎。

珍贵装备不应因一次普通攻击直接消失，除非玩家明确接受风险或攻击本身具有摧毁法宝的能力。

## 14. 战斗结果

| 结果 | 建议条件 |
|---|---|
| 完胜 | 获胜者生命高于75%，没有新增重伤，重要装备完好 |
| 胜利 | 获胜者仍可正常行动，损耗能够承受 |
| 惨胜 | 获胜者生命不高于40%，或出现重伤、修为损伤、重要装备损坏 |
| 逃脱 | 一方通过追逐、隐匿、传送或断后成功脱离 |
| 被俘 | 一方昏迷、投降或被控制，胜者选择留其性命 |
| 两败俱伤 | 双方都失去继续作战能力 |
| 死亡 | 达到死亡条件且没有救命手段 |

“被击败”不等于“死亡”。除非攻击造成不可挽回的致命伤，否则胜者仍需要决定处决、俘虏、救治或放走对手。

## 15. 范例人物：林照微

- 等级：27
- 境界：筑基后期
- 身份：青岚剑院外门弟子
- 灵根：火单灵根，火属性功法经验倍率1.30
- 当前状态：左臂旧伤，刀剑与御剑检定−10

| 力量 | 体魄 | 敏捷 | 智识 | 意志 | 灵觉 | 魅力 |
|---:|---:|---:|---:|---:|---:|---:|
| 9 | 11 | 15 | 12 | 13 | 17 | 7 |

- 最大生命：55
- 最大灵力：84
- 先攻值：32

| 技能 | 技能值 |
|---|---:|
| 御剑 | 84 |
| 身法 | 57 |
| 火行术法 | 71 |
| 坚韧 | 52 |
| 洞察 | 45 |

功法为58级《赤阳归元诀》，火属性攻击的功法乘区为1.29。天赋为“烈焰直觉”和“临危不乱”。装备包括基础威力9、火纹加值3、耐久12的玄铁火纹剑，以及护甲4、耐久10的青纹软甲。

## 16. 范例战斗：雪谷遭遇战

林照微在风雪山谷遭遇25级寒潭妖狼。妖狼处于筑基中期，最大生命60，寒冰爪65，闪避54，逃脱55，坚韧40；冰寒血脉提供1.20功法乘区，皮毛提供2点护甲，并具有火弱点5。

环境令火属性检定−10、火伤害乘区0.90、冰属性检定+10、冰伤害乘区1.10；妖狼的雪地闪避与逃脱+5，不适应雪地者的身法−10。

### 第一轮：火焰剑招

林照微的御剑84受到左臂旧伤−10和风雪−10，目标值为64。他投出21，进入大成功范围。妖狼闪避目标值59，投出73，结果为失败。攻击胜出两个最终等级，构成重击。

该攻击的原始威力来自武器9、力量3、火纹3和招式6；随后应用重击、功法、同境界、风雪和随机波动乘区，再扣除护甲2，最后加入火弱点5。最终造成41点伤害。

妖狼生命由60降至19，低于30%，获得重伤，肉身行动−15。

### 第一轮：妖狼反击

寒冰爪65受到风雪+10和重伤−15，目标值为60。妖狼投出32，获得成功。林照微的身法57受雪地−10，目标值47，投出44，也获得成功。妖狼的内部表现更高，因此普通命中。

冰爪经过血脉、环境、随机波动和软甲减伤后造成16点伤害。林照微生命由55降至39，并获得一项胸腹轻伤。

### 第二轮：逃脱与俘获

妖狼尝试逃脱。其逃脱技能经过雪地和重伤调整后目标值45，投出46，属于惜败；林照微追击目标值47，投出18，成功封住谷口。

林照微决定使用剑柄进行非致命攻击，额外承受−10。最终目标值54，投出12，获得大成功。妖狼闪避失败，受到11点非致命伤害，生命降至8，并因重伤状态下遭受非致命重击而进行坚韧检定。妖狼大失败并昏迷。

### 最终结果

- 林照微剩余生命39/55，约71%。
- 林照微新增胸腹轻伤，但没有新增重伤。
- 妖狼重伤、昏迷并被缚妖索控制。
- 双方均未发生修为损伤。
- 林照微的装备没有损坏。

结算为：林照微取得普通胜利，并成功俘获寒潭妖狼。由于生命低于75%，这不是完胜；由于仍保有大部分生命且没有新增重伤、修为损伤或装备损坏，也不是惨胜。
