# 轻量肉鸽实现纲要 v0.1

本文件是《修行战斗规则 v1.0》的试玩版实现约束。原规则继续作为底层公式库和后续扩展参考，但不等于玩家需要阅读的界面。

## 一、玩家只看必要信息

人物常驻面板只显示五维：攻击、防御、速度、智力、熟练度。气血和灵力作为两条独立资源显示，不塞进五维。

战斗完全自动。战斗小窗最多展示四项关键比较，例如先手、破势、承伤和灵根应变；比较结束后立即展示胜负、受伤、消耗与奖励。d100 八档、乘区、护甲顺序和环境修正均留在程序内部，除非玩家主动展开详情。

## 二、轻量成长节奏

- 前期（锻体、练气）：资源紧、选择少、常有险胜，让一次属性增加或一件普通装备都能被感知。失败应提供情报、熟练度或新路线，避免纯粹浪费时间。
- 中期（筑基至化神）：功法、灵根和装备开始联动，普通战斗快速碾过，精英战才要求判断风险。玩家应明显感觉构筑已经成形。
- 后期（炼虚以后）：允许大范围压制、连续突破和夸张收益。少数顶级敌人保留威胁，其余内容服务于“特别爽”的兑现感。

早期受苦不能靠拖长战斗实现。单场普通战斗应在一次结算内结束，困难来自资源取舍、错过机会和是否接受风险。

## 三、任务与境界绑定

主线严格绑定当前境界：突破后立即推送该境界主线和清晰目标，并标明必须在下一次突破前完成。没有完成时不允许无提示地跨境界。

支线由境界、灵根、属性、物品、人物关系或过去选择解锁。解锁只代表进入“可触发”状态，玩家仍要在合适地点或选项中主动触发。

## 四、灵根不是简单稀有度

沿用金、木、水、火、土五行，并生成一至五种灵根。灵根数量只改变成长曲线、天赋和剧情入口，不直接决定最终上限。

- 一灵根（天灵根）：前期修炼顺、容易被奉承和争抢，也更容易卷入名望支线。
- 双灵根：较快形成相生构筑，初期容错更高。
- 三灵根：成长稳定，五维不容易偏科。
- 四灵根：前期略慢，擅长环境和克制，奇遇面更广。
- 五灵根：开局可能被 NPC 嘲讽，初期熟练度略低；突破时有额外成长，并拥有五行归一支线，后期潜力不弱于天灵根。

## 五、第一段试玩流程

1. 玩家进入世界，从出生事件开始。
2. 程序一次性 Roll 出五维、气血、灵力、灵根和先天天赋，并保存到本地。
3. 立刻收到“锻体境主线”，同时按灵根解锁一条可触发支线。
4. 玩家选择一次童年修行，获得两点以内的可见成长。
5. 玩家决定进入木傀试炼；程序自动比较四项关键数值。
6. 右侧小窗立即展示战斗过程摘要和最终结果。失败不会在序章死亡，并获得熟练度后可重试。

这段试玩只验证出生、Roll 点、主支线状态、选择成长和自动战斗五件事，不提前加入完整装备、功法、伤势、转生与多人同步。

## 六、自由行动、背景拓展与主线分支

目标不是为每个 NPC 和道具手写一套孤立菜单，而是建立“通用动作 + 对象标签 + 特殊覆写 + 世界后果”系统。玩家原则上可以尝试任何动作，但“能够尝试”不等于“必定成功”或“必定有意义”。程序先给出通用反馈，命中特殊组合时再进入专属剧情。

### 6.1 NPC 通用行动

遇见一个人物时，默认提供四个醒目的推荐行动，并把其余行动收进“更多行动”，避免页面一下出现十几个按钮：

1. 观察：判断境界、伤势、态度、装备和是否说谎。
2. 交涉：询问、劝说、套话、招募、求助或交换情报。
3. 交易：购买、出售、以物易物、议价或赊欠。
4. 敌对：威胁、偷窃、抢夺、挑战或尝试杀死。

黑暗路线中的“侵犯”统一定义为非性化的“侵害”：搜魂、种下禁制、强制契约、夺舍或侵占对方利益。它不等同普通攻击，可能快速取得情报、控制权或资源，但会产生严重的因果、仇恨、通缉、心魔和阵营变化。非自愿性行为不作为可操作玩法。

所有敌对动作都使用“尝试”措辞。玩家能看见大致风险、可能引来谁以及失败代价，但看不到完整公式。对境界差距过大的目标尝试杀死，程序必须明确显示“近乎必死”，不能伪装成普通选项。

### 6.2 道具通用行动

获得任何道具后，至少允许尝试以下操作：

- 观察或鉴定：发现名称、材质、来历、隐藏效果和危险。
- 使用：对自己、人物、场景或另一件道具使用。
- 吃掉：食品正常生效；药材可能生效或中毒；石头等物品也允许尝试，但会得到符合常识的失败反馈。
- 装备或携带：只有具备相应标签时进入装备位，否则只是普通携带。
- 组合：炼制、镶嵌、修复、点燃、浸泡、书写或作为钥匙。
- 赠送或交易：改变人物关系、价格和后续事件。
- 破坏：拆解、焚烧、碾碎、抹除印记，可能产出材料或释放危险。
- 扔掉：移出背包并在当前地点留下记录，未来可能被别人捡到。

无用操作不能只有一句“无法使用”。系统应根据材质、危险、灵性和角色状态给出短反馈，并区分：毫无效果、操作失败、付出代价、意外发现、隐藏奇效五类结果。

### 6.3 场景通用行动

地点和机关也作为可操作对象：观察、搜索、进入、采集、破坏、布置、标记、等待和离开。人物、道具、地点使用同一套标签规则，例如“火属性 + 可燃”“家书 + 祖祠”“青鳞 + 枯井”会得到特殊结果。

### 6.4 结果计算顺序

1. 确认行动对象仍存在，防止重复点击旧页面。
2. 检查硬性条件：是否有目标、道具数量、地点、境界和世界状态。
3. 展示风险：低、中、高、极高、近乎必死，以及主要判定属性。
4. 收集人物背景、灵根、天赋、功法、技法、关系和道具修正。
5. 优先匹配专属覆写；没有专属内容时使用标签通用结果。
6. 计算成功档位：大失败、失败、成功、大成功或特殊结果。
7. 一次性结算气血、灵力、物品、关系、因果、通缉、人物状态和世界标记。
8. 把结果写入履历与存档，再刷新页面，避免 F5 重抽或重复领奖。

### 6.5 主线不能被自由度卡死

重要 NPC 可以被杀、赶走、控制或拒绝，但主线信息和关键物不能因此永久消失。每个主线节点至少准备三条继续方式：

- 正常路线：本人交付任务或道具。
- 敌对路线：战利品、搜魂、尸体线索、遗书或仇家接手。
- 错过路线：继承人、替代地点、世界流言或若干日后重新出现。

这三条路线可以改变奖励、关系和结局，但都必须让玩家理解下一步在哪里。自由不是“随便点错就坏档”，而是玩家用不同代价抵达不同版本的后续。

### 6.6 控制组合爆炸

内容作者只写真正值得专属演出的组合，其余由程序生成简短合理反馈。优先级从高到低为：

1. 事件专属覆写。
2. 人物或物品专属覆写。
3. 标签组合规则。
4. 通用动作结果。
5. 常识兜底结果。

例如“家中旧信”对木傀试炼无用，对祖祠石门却是专属钥匙；“驱虫香”可以正常点燃、可以破坏，也能在灵田虫灾中直接产生奇效。这样每件道具都有自由操作，但不需要人为穷举所有排列组合。

### 6.7 轻量界面约束

- 当前事件页最多展示四个推荐行动。
- “更多行动”展开全部通用动作。
- 玩家选定对象后再选动作，不同时铺开所有人物和物品。
- 右侧小窗只显示主要属性、关键修正、风险目标和最终结果。
- 详细因果与世界变化收进履历，避免一次结算刷满屏幕。

通用动作和组合优先级配置在 `public/游戏内容/自由行动/自由行动规则.json`。后续人物、物品与主线 JSON 只需要填写标签和少量 `overrides`，便可接入同一套流程。
