# 自由行动算法 v1.0

本算法负责人物、道具、地点、机关与尸体的通用行动判定。内容作者只需要填写对象属性、标签、数值特征和少量特殊覆写，不需要自己计算概率。

## 一、一次行动的数据

每次行动必须同时确定：行动者、主要目标、可选的次要目标、当前世界、动作 ID、修正项与尝试 ID。点击确认时先把尝试 ID 写入存档，同一 ID 永远得到同一个点数。

## 二、成功率公式

```text
成功率 = 限制到动作上下限(
  动作基础率
  + (行动者检定值 - 目标检定值) × 4
  + 等级差修正
  + 关系修正
  + 状态与标签修正
  + 环境与目击者修正
  + 功法技法修正
  + 道具修正
  + 剧情专属修正
  + 连续尝试惩罚
)
```

行动者与目标检定值由五维加权平均得到。例如偷窃使用“速度 60% + 智力 20% + 熟练度 20%”，目标使用“速度 40% + 智力 30% + 熟练度 30%”。一点有效五维差通常等于 4% 成功率。

等级差按动作分别计算。交涉和交易受等级影响很小，威胁、抢夺、杀死和侵害受等级影响很大。单次等级修正最终限制在 -35% 到 +35%，避免纯等级完全覆盖人物构筑。

功法、技法、道具、状态、环境和剧情修正分别限制在 -60% 到 +60%，防止错误内容把概率推到数百。

## 三、主要动作比较

| 动作 | 行动者主要属性 | 目标抵抗 | 特点 |
|---|---|---|---|
| 观察 | 智力 70%、熟练度 30% | 智力、熟练度、隐藏度 | 同级基础成功率较高 |
| 交涉 | 智力 70%、熟练度 30% | 智力、熟练度、意志 | 关系值最多可带来约 ±20% |
| 交易 | 智力 75%、熟练度 25% | 对方同属性与议价 | 商人、出身和关系影响明显 |
| 帮助 | 熟练度 60%、智力 40% | 问题严重度 | 受伤目标更容易出现有效帮助机会 |
| 威胁 | 攻击 50%、智力 25%、熟练度 25% | 防御、智力、熟练度、勇气 | 等级优势很重要，失败会结仇 |
| 偷窃 | 速度 60%、智力 20%、熟练度 20% | 速度、智力、熟练度、警觉 | 地点和目击者影响最大 |
| 抢夺 | 攻击 55%、速度 25%、熟练度 20% | 防御、攻击、速度 | 失败或大失败转入战斗 |
| 攻击 | 速度 50%、智力 20%、熟练度 30% | 对方同属性与警觉 | 只决定开战先手，不直接决定胜负 |
| 杀死 | 攻击 45%、速度 35%、熟练度 20% | 防御、速度、熟练度、警觉 | 转入致死战斗，单次检定不能秒杀同级人物 |
| 侵害 | 熟练度 50%、智力 30%、攻击 20% | 熟练度、智力、防御、意志 | 非性化黑暗路线；成功也产生因果和心魔代价 |
| 鉴定 | 智力 70%、熟练度 30% | 物品复杂度 | 普通物品容易，秘宝需要传承或工具 |
| 使用 | 熟练度 60%、智力 40% | 物品复杂度 | 专属覆写优先于普通检定 |
| 吃掉 | 防御 100% | 毒性和物品标签 | 食物固定成功，药材与毒物检定，矿石按常识失败 |
| 组合 | 熟练度 60%、智力 40% | 两件物品综合复杂度 | 配方覆写命中时可直接进入特殊结果 |
| 破坏物品 | 攻击 70%、熟练度 30% | 耐久度 | 关键物需要二次确认，并保留替代主线路线 |
| 搜索 | 智力 60%、熟练度 25%、速度 15% | 隐藏度 | 遗迹环境有利，重复搜索逐次降低成功率 |

完整数值保存在 `public/游戏内容/自由行动/自由行动规则.json` 的 `actionProfiles` 中。

## 四、概率与四档结果

程序掷 1—100：

- 大成功：点数不高于 `min(成功率, clamp(5, 30, 成功率 - 50))`。
- 成功：点数不高于成功率。
- 失败：点数高于成功率，但尚未进入大失败区。
- 大失败：点数不低于 `clamp(55, 96, 成功率 + 30)`。

低成功率不会被“大成功最低 5%”反向抬高。例如最终成功率为 1%，大成功区也最多只有 1%。高成功率会提高大成功占比并压低大失败占比。

玩家默认只看一个概率区间。智力越高，区间越窄；内部仍保存精确概率和全部修正，方便平衡与 Bug 报告。

## 五、风险分级

- 80%—100%：低风险。
- 60%—79%：中风险。
- 40%—59%：高风险。
- 0%—39%：九死一生。
- 对高出玩家至少十级的目标发动敌对行动：强制显示“十死无生”，成功率最高 5%。
- 对高出玩家至少二十级的目标发动敌对行动：进入 `absolute_death` 档，成功率为 0%；显示文字由 JSON 配置。

“十死无生”只用于可能致命的敌对行为。吃石头或破坏坚硬物品即使成功率很低，也只显示“九死一生”，不误导成死亡威胁。

## 六、攻击与战斗转交

攻击和杀死的自由行动检定只决定是否抢到先手：大成功 +2、成功 +1、失败 +0、大失败 -2。“杀死”把后续战斗标记为致死战，由战斗系统决定双方实际伤亡。抢夺成功可直接取得目标物，失败时转入战斗。

这样既允许玩家尝试杀死任何人，也不会用一次幸运检定绕过完整战斗数值。

## 七、状态、环境与连续尝试

- 气血低于 25%：物理行动 -10%。
- 灵力低于 25%：精神与灵力行动 -10%。
- 重复对同一对象使用同一动作：每次 -10%，最多 -30%。
- 偷窃、抢夺、杀死和侵害：每名目击者 -3%，最多 -15%。
- 村镇、安全区和守卫区域降低敌对行动成功率；荒野与遗迹提高搜索或潜行机会。
- 受伤、被束缚和无力反抗是不同标签，分别影响帮助、偷窃、抢夺、杀死与侵害。

## 八、固定、标签和专属结果

结算优先级：事件专属覆写 → 对象覆写 → 标签组合 → 动作兜底 → 常识兜底。

- 固定动作：离开、正常丢弃，不掷点。
- 标签驱动：吃食物固定成功；吃毒物检定；吃矿石按常识失败且通常不消耗物品。
- 专属覆写：祖祠使用家书、灵田使用驱虫香等，可修改概率、强制结果、追加效果或转入新系统。

## 九、防重抽与结算顺序

1. 点击确认后先生成并保存 `attemptId`。
2. 世界种子、attemptId、人物、目标和动作共同生成固定点数。
3. 资源不足或目标失效时拒绝结算，不扣成本。
4. 可执行时先扣行动成本，再应用剧情效果。
5. 保存 `resolutionId = free-action:attemptId`，相同结算只允许应用一次。
6. 最后写入履历、人物状态、物品状态、世界时间和主线改道。

同一个 attemptId 刷新多少次都得到相同结果，避免刷新刷大成功或网络重试重复领奖。

## 十、内容平衡目标

- 普通同级观察：约 65%—75%。
- 普通同级交涉与交易：约 50%—70%。
- 有目击者的村镇偷窃：约 20%—35%。
- 正确帮助受伤人物：约 60%—75%。
- 强拆高耐久物品：可低至 10%—20%。
- 越十级主动杀敌：最高 5%，并明确近乎必死。

使用 `pnpm actions:simulate` 可跑五千次统计样本；使用 `pnpm content:check` 可检查动作引用、权重、事件 ID 和物品引用。
