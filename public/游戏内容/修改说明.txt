《轮回仙途》快速修改文字

一、怎么打开
双击项目根目录里的“打开内容配置.bat”，会直接打开本文件夹。

二、怎么修改
1. 用记事本打开“界面文字.json”。
2. 只修改双引号里面的文字，不要删除字段名、冒号、逗号或括号。
3. 保存文件。
4. 关闭当前游戏的黑色窗口，再双击“一键启动互联网联机.bat”。
5. 无需重新构建，重新打开的页面会读取新文字。

如果要修改序章内容，请打开“序章规则.json”。这里可以直接调整：
- 出生五维范围、气血与灵力换算；
- 灵根出现权重、灵根天赋、NPC 反应和初始加成；
- 主线与支线文案、解锁条件和属性奖励；
- 童年修行选项、风险提示和属性成长；
- 出身概率、初始灵石、道具、功法、技法与隐藏天赋；
- 木傀战斗目标值、随机波动、受伤范围和结算文字；
- 死亡回退规则说明与多人遗迹预告。

三、怎么增加世界大事件
在“序章规则.json”的 worldSystem.events 方括号中增加一项。

直接公告使用：
{
  "id": "唯一英文编号",
  "title": "事件标题",
  "startDay": 1,
  "endDay": null,
  "mode": "direct",
  "summary": "公告摘要",
  "detail": "玩家直接看见的完整内容"
}

需要去城镇打听的事件使用 mode: "storyteller"，并填写：
- storytellerTownId：说书人所在地点的 id；
- timeCostDays：打听事件会消耗的世界天数。

startDay 是事件开始出现的世界日。endDay 填 null 表示以后一直有效；填写数字则在该世界日之后消失。

四、怎么增加地图地点
在 worldSystem.locations 方括号中增加地点。id 必须是唯一英文编号；name 和 description 可以写中文。
- type 填 town 时，玩家到达后可以投宿休息；填 wild 时是野外地点；
- x 和 y 是简易地图坐标；两个地点坐标相差越远，行路耗时越长；
- 玩家速度会换算成脚力，脚力越高，前往同一地点消耗的天数越少；
- startingLocationId 决定新人物从哪个地点开始。

五、时间和寿元
- 现实每过 1 分钟，世界自动流逝 1 天；
- 修行、支线、战斗、行路、投宿和打听事件都会立即增加世界天数；
- training.choices、sideQuests、trial 和事件中的 timeCostDays 控制行动耗时；
- lifespan.baseDays 是基础寿元，daysPerDefense 表示每点防御（当前作为体质）增加多少天；
- realmBonusDays 表示不同境界额外增加的寿元；
- 寿元耗尽后，本世不能继续行动，需要转生。

六、注意事项
- JSON 使用英文半角双引号和逗号。
- 最后一项后面不要加逗号。
- 如果格式写错，网页会继续使用上一次构建时的默认文字，不会破坏世界存档。
- “界面文字.json”只负责文字，不会修改玩家、房间或世界存档。
- “序章规则.json”中的 rootRoll 使用 weight 表示相对概率。数值不必刚好加到 100，数字越大越容易抽到。
- 灵根名称中的 {elements} 是元素占位符，游戏会自动换成“金·木·水”等实际结果。
- 支线 unlock 为 null 时会直接解锁；填写 stat 和 minimum 时，会检查指定五维是否达到要求。
- 世界大事件、地图和寿元配置位于 worldSystem。
- origins 控制出身。修真世家的 startingCultivationRoll 会按 weight 再抽取一部功法。
- cultivationArts、techniques 和 items 是内容目录；出身中填写对应 id，人物才会实际拥有它。
- 道具 effects 中的 contextId 决定生效场景。木傀试炼使用 wooden_trial；场景不匹配时会提示无用，不加入计算也不消耗。
- 玩家可以同时备好任意数量的有效道具。consumable 为 true 的道具只在实际生效后扣除一个，false 则永久保留。
- bonusWins 或 forceOutcome 可制作特定地点的奇效；specialResult 可先记录未来事件效果。
- hiddenTalentId 会写入角色存档但不会直接显示，等满足 revealCondition 后再由事件揭示。
- 战斗在玩家点击开战时即时计算；JSON 负责可调整参数和文案，程序负责公式、比较与结算。
- worldRules 目前是下一阶段的规则与入口配置；真正的全员死亡回退和遗迹同步尚未启用。
- 新规则主要作用于新出生的人物。已经开始的角色会保留出生时的气血和灵力规则，避免中途变数值。
- 提交到 GitHub 后，其他组员也能同步这些文字修改。

目前 worldSystem.events 是第一版世界事件库；复杂分支剧情仍会在后续拆分成独立“事件库.json”。建议每次只改一个小部分，保存后重启试玩确认。
